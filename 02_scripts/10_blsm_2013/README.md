# BLSM 2013 — IFLS4/IFLS5 audit

This module audits cash transfer codes, timing, tracking, consumption components and analytical feasibility before fitting ATT or RAPSEM. Run R scripts from the root of `IFLS_Project.Rproj`. Raw IFLS data must remain local. The scripts should never redefine unanswered program questions as nonreceipt.

**Analysis unit:** not yet finalized. Evaluate stable households and linked individuals separately due to household split-offs.

**Research target:** effect of household BLSM receipt in 2013 on changes in real monthly household consumption per capita between IFLS4 (2007–08) and IFLS5 (2014–15), conditional on defensible identification assumptions. This is an ATT objective; no estimation until treatment and outcome definitions are verified.
